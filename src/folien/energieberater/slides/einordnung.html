Was Speicherklar ist und was nicht

Speicherklar ist

  • ein unabhängiger Rechner für PV-Anlage und Stromspeicher
  • die zweite Rechnung zum Angebot, vor der Unterschrift
  • offen: Rechenweg und Code liegen auf GitHub

Speicherklar ist nicht

  • eine Beratung vor Ort
  • eine Verschattungsanalyse oder Elektroplanung
  • ein Vermittler: keine Provision, keine Leads, keine Partner-Installateure

Passt ein Angebot, sagt der Bericht das auch.

SPEICHERKLAR

02 / 14

Speicherklar ergänzt Ihre Arbeit, es ersetzt sie nicht. Was vor Ort zu klären ist, etwa Verschattung oder Notstrom, bildet das Modell bewusst nicht ab. Dazu später mehr.
